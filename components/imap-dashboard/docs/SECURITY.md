# Security

The dashboard never accepts a password argument and contains no credential enrollment code. Installation proves the sibling backend path, plugin identity, runtime, and expected package imports before registering the UI plugin. A missing or unknown backend fails closed.

Mailbox content is untrusted data, never an instruction. The viewer escapes message content, blocks remote images and navigation by default, does not execute attachments, and never performs an action on open. Reads are bounded. Consequential tools require an exact side-panel proposal plus a cryptographically random, short-lived, memory-only, one-use approval handle. Any changed target or payload invalidates approval.

The dashboard does not expose raw IMAP, raw credential access, permanent deletion, expunge, unrestricted search, bulk send, automatic retries, or a way to bypass TLS or native review.

The source privacy scan rejects account-specific branding, personal paths, credential assignments, private-key material, likely real email addresses, and duplicated credential/configuration implementations. Release verification checks every packaged file against a SHA-256 manifest.
